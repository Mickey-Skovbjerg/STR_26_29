## A2b: Identify claim
We have chosen to use building #2602. <br>
Our claim is "to automatically name structural elements based on their placement, type and material when making the calculations of vertical load distribution". When doing the vertical load distribution, you first have to name each structural element, so that you can make a caluculation file with a name corresponding to that element. The naming is often made manually with human mistakes. It can sometimes be unstructured and confusing in the long run, especially when dealing with load take downs.

## A2c: Use case
We could check if the number of structural elements in the model is the same as the number of names we get from the tool. If we do an automatically generated drawing, we would check if it aligns with the manually drawn model. We will check if the tool made the right assumptions on which kind of element it is, (beam/column/wall/slab etc.).

When using the tool, you need to check if the drawings align with the manually drawn drawings, and check if there are missing elements, or if there are duplicate elements. This could be a sign that there is something wrong with their model. But the tool needs to be tested in multiple ways before it can be used.

This claim relies on the information of the IFC type for columns, slabs, beams and walls. There should also be information about the length, orientation, cross section, as well as the position of the element in the x, y, and z axis.

The tool will be needed in the early design phases, and might be used iteratively, if structural members are added or left out.

Considering BIM purposes, the tool will *gather* model informations about the placement, dimensions, type etc. The tool will then *generate* names based on these informations. And lastly, it will *communicate* the information via an automatically created drawing, showing the placement and names of each element.

## A2e
The traditional method of naming elements is to look at a pdf or a plan drawing, and naming the elements as the calculations are carried out.

The tool primarily provides business value by reducing the time structural engineers spend naming construction elements for vertical load distribution. It is specifically designed as a tool for structural engineers and does not directly simplify the overall building design process. Therefore, its impact is primarily professional and economic rather than social.

## A2f
The information that needs to be extracted from the tool is the placement of the elements within the grid and the element names. The element name is needed to identify what type of element it is, while the placement is important when there are multiple elements on the plan, as it makes it easier to determine where each element is located within the grid.
