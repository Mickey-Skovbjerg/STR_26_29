# STR_26_29
This report presents the work of Group 29 in course 41934 Advanced Building Information Modeling. It consists of three assignments that together form one project: a tool that supports structural engineers in naming structural elements and their corresponding calculation files during vertical load distribution of a building. Names are generated automatically from each element's position on the grid, its type, and its material.

##A1: Forensic BIM
In the first assignment, we became familiar with the core concepts of OpenBIM. The assignment describes our focus area, the issue we identified, and a possible solution.

##A2: Use Case
In the second assignment, we identified a use case that we are passionate about and want to develop a tool for in A3. It specifies the building we chose to work with and describes the tool we intend to build to solve the identified issue.
